# MCP Research Assistant — Student Starter

This is the student-facing scaffold. Implement the `TODO` stubs in
`src/mcp_research/`, then run the autograder:

```bash
python -m pytest tests/test_arxiv_tools.py tests/test_config.py -q   # offline
```

The full assignment handout (background, tasks, how to run for real, how to
explore the server in the MCP Inspector) is in the parent directory's
[`README.md`](../README.md).

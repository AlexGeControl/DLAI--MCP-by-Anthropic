## Verdict

**Modernize before refactoring — moderate urgency, one genuine teaching hazard.**
The course is in good shape conceptually and most APIs are stable, but it ships **one
deprecated transport** (`SSE`, the entire point of the remote-server lesson), a **retired
model id**, and **two junk dependencies**. None of these block *understanding* MCP, but
following the assignments verbatim today will teach one dead pattern and produce a noisy
environment. Estimated course vintage: **~April–May 2025** (mcp 1.7–1.8, anthropic 0.50–0.51).

## Migration notes (old → new)

### 1. SSE → Streamable HTTP (the important one)
```python
# OLD (L9 research_server.py) — deprecated standalone SSE transport
mcp = FastMCP("research", port=8001)
mcp.run(transport='sse')

# NEW — Streamable HTTP (SSE is now just an optional streaming channel inside it)
mcp = FastMCP("research", host="0.0.0.0", port=8001)
mcp.run(transport='streamable-http')
```
Clients connect via `streamablehttp_client(url)` (from `mcp.client.streamable_http`)
instead of the old `sse_client`.

### 2. Model id
```python
model = 'claude-3-7-sonnet-20250219'   # OLD
model = 'claude-sonnet-4-6'            # NEW (current Sonnet; or claude-haiku-4-5 for cheap/fast)
```

### 6. Drop the nest_asyncio hack
```python
# OLD
from anthropic import Anthropic
import nest_asyncio; nest_asyncio.apply()
self.anthropic = Anthropic()
resp = self.anthropic.messages.create(...)        # sync call inside async code

# NEW
from anthropic import AsyncAnthropic
self.anthropic = AsyncAnthropic()
resp = await self.anthropic.messages.create(...)  # native async, no monkey-patch
```

### 5 & 7. Clean the dependency set
Remove `typing`, `pypdf2` (both junk), and `nest-asyncio` (after #6). Resulting core:
```toml
dependencies = [
    "anthropic>=0.105",
    "arxiv>=2.2",
    "mcp>=1.27",
    "python-dotenv>=1.1",
]
```

## Modernization plan (hand-off to `assignment-refactor`)

2. **Should-fix (currency):** model id → Claude 4.x (#2); `AsyncAnthropic`, drop `nest_asyncio` (#6); bump `mcp`/`anthropic` floors (#3, #4); drop `pypdf2` (#7).
3. **Optional:** Docker base bump (#9).

local) is **fully current** — modernization is surgical, not structural.

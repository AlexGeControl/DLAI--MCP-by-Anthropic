# Lesson 12 — Appendix: Tips and Help

> **One-line:** Reading-material reference on accessing and downloading the course notebooks and files.

## What's here

This is a non-video appendix (`reading_material`) — no transcript. It covers practical logistics rather
than MCP concepts:

- **Accessing the notebooks** — each coding lesson's Jupyter notebook lives in the course workspace
  (mirrored under `raw/assignments/L*/`).
- **Downloading the files** — how to pull the notebooks and the `mcp_project/` source (e.g.
  `research_server.py`, `mcp_chatbot.py`, config JSON) to run locally.
- **Running locally** — recreate the environment with `uv` (`uv init` / `uv venv` / `uv add ...`), as
  shown in [[05-creating-an-mcp-server]].
